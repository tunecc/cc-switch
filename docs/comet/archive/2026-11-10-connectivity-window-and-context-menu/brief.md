# 目标

两个 UI 修复：

1. **连通性测试弹窗内容可见性**：`ConnectivityTestDialog` 当前 `max-w-2xl` 且无高度约束，内容（基础参数、高级参数折叠区、五张统计卡、模型表格、免责声明、底部按钮）在小窗口下被截断或挤压，用户看不到内容。修复后弹窗内容在常规窗口尺寸下完整可见、可滚动。

2. **供应商右键菜单合并**：现在右键点击供应商卡片弹出的自制小菜单只有「一键置顶 / 一键置底」两项；卡片上的「更多」下拉菜单（`ProviderCardActions`）有模式项、复制、连通性测试、用量配置、删除。用户希望右键菜单直接展开为完整菜单：置顶 / 置底 + 现「更多」菜单里的全部内容，不再需要先点「更多」。

结论取向：右键复用 Radix `DropdownMenu`/`ContextMenu` 的完整菜单内容，置顶/置底两项并入同一菜单；保留现有自制小菜单的位置定位行为（出现在鼠标位置）或改用等价的 ContextMenu 组件，以实现时选择最稳妥的为准，行为等价即可。

# 范围

## 目录结构

### 修改

- src/components/providers/ConnectivityTestDialog.tsx — 弹窗尺寸与内容布局：加宽（如 max-w-4xl）并给内容区合理的最大高度 + 内部滚动，保证各区域可见。
- src/components/providers/ProviderList.tsx — 右键菜单改造：菜单项扩展为置顶/置底 + 「更多」全部菜单项；菜单打开时项的回调需要透传到卡片动作。
- src/components/providers/ProviderCardActions.tsx — 抽取/复用「更多」菜单项渲染逻辑，使右键菜单能复用同一套菜单项（模式项、复制、连通性测试、用量配置、删除及禁用原因展示）。

# 非目标

- 不改动卡片上「更多」按钮本身的存在与否（右键是补充入口；「更多」按钮保留）。
- 不改动连通性测试的后端逻辑、测试流程、参数表单字段。
- 不改动拖拽排序、故障转移顺序逻辑（置顶/置底沿用现有 applyQuickSort）。

# 验收示例

- A1: 打开连通性测试弹窗（含多个模型行、高级参数展开时），在默认窗口尺寸下弹窗内所有区域（参数区、统计卡、模型表格、免责声明、底部按钮）均可见或可通过弹窗内滚动到达，无内容溢出被截断。
- A2: 弹窗宽度不小于当前 max-w-2xl，模型表格的列（勾选、模型、状态、首字节、总耗时、错误信息、操作）不再出现因宽度不足被挤压换行到不可读。
- A3: 右键点击任意供应商卡片，弹出的菜单包含：一键置顶、一键置底，以及原「更多」菜单的全部项（模式相关项、复制、连通性测试、用量配置、删除），无需再点击「更多」按钮。
- A4: 右键菜单中置顶/置底的排序行为与原小菜单一致（写 sortIndex、刷新列表与托盘菜单、toast 提示、已在顶部/底部时提示不变）。
- A5: 右键菜单中删除项的禁用原因展示、连通性测试禁用态（isTesting）、模式项的子菜单行为与原「更多」菜单一致；点击任一项后菜单关闭且动作正常执行。
- A6: 卡片上的「更多」按钮菜单行为不变（原有项与顺序不受影响）。
